# XG5000 Device Map

PLC 디바이스의 참조 관계를 시각화하는 Windows 프로그램입니다. 여러 스캔 프로그램에서 디바이스가 어디에 사용되는지 관계도로 탐색할 수 있습니다.

XGB-XBCU와 XGB-XBMS 각각의 XG5000 프로젝트(`.xgwx`)를 직접 여는 기능을 개발하고 있습니다. 현재 배포본은 비 IEC 래더 형식의 XGWX 파일과 예제·전용 JSON 파일을 읽습니다. 두 기종의 실제 프로젝트 호환성은 검증 중입니다.

## 다운로드

1. [Windows 설치 파일 빌드 목록](https://github.com/minsoo0506/xg5000-device-map/actions/workflows/windows.yml)에서 초록색 체크 표시가 있는 최신 실행을 엽니다.
2. **Artifacts → XG5000-Device-Map-Windows-Installer**를 내려받습니다. GitHub 로그인이 필요할 수 있습니다.
3. 압축을 풀고 `-setup.exe` 파일을 실행해 설치합니다.
4. 시작 메뉴에서 **XG5000 Device Map**을 실행합니다.
