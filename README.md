# XG5000 Device Map

XG5000 디바이스의 관계를 살펴보기 위한 Windows용 시제품입니다.

## 설치 및 실행

1. GitHub 저장소의 **Actions → Windows installer**에서 완료된 실행을 선택합니다.
2. **Artifacts**에서 `XG5000-Device-Map-Windows-Installer`를 내려받아 압축을 풉니다.
3. `-setup.exe`를 실행하고 설치한 뒤 시작 메뉴에서 **XG5000 Device Map**을 엽니다.

설치 파일에는 오프라인 WebView2 설치 구성 요소가 포함됩니다. 회사 PC의 설치 정책에 따라 실행이 제한될 수 있습니다.

## 사용 방법

- **예제 열기**를 누르면 가상의 컨베이어 데이터가 열립니다.
- 왼쪽에서 주소 또는 주석을 검색하고 디바이스를 선택합니다.
- `+`와 `−`로 관계 탐색 단계를 조절하고, 관계도의 디바이스를 클릭해 중심을 바꿉니다.
- 조건 묶음을 클릭하면 프로그램, 위치, 읽기 및 쓰기 명령을 확인합니다.
- **관계 데이터 열기**로 아래 형식의 UTF-8 JSON 파일을 불러올 수 있습니다. 데이터는 로컬에서 처리됩니다.

```json
{
  "name": "예제",
  "devices": [
    {"address": "P000", "comment": "기동 버튼"},
    {"address": "M100", "comment": "운전 허가"}
  ],
  "rungs": [
    {
      "id": "main-10",
      "program": "MAIN",
      "location": "스텝 10",
      "reads": ["P000"],
      "writes": [{"address": "M100", "instruction": "OUT"}],
      "note": "원본에서 확인한 설명"
    }
  ]
}
```

`id`와 디바이스 주소는 각각 중복될 수 없으며, `reads`와 `writes`의 주소는 `devices`에 정의되어야 합니다.

**현재 제한:** XG5000 프로젝트 파일, 래더, 변수 CSV를 직접 분석하지 않습니다. 위 JSON은 이 프로그램의 전용 형식이며 XG5000 내보내기 형식이 아닙니다. 표시되는 연결은 입력된 참조 관계이며, 접점 논리·스캔 순서·실제 동작을 증명하지 않습니다. 실제 설비의 판단에는 반드시 원본 래더를 확인하세요.
