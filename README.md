# XG5000 Device Map

LS 산전 PLC의 XG5000 프로젝트 파일(`.xgwx`)을 열어 디바이스 참조 관계를 살펴보는 Windows 프로그램입니다. 주소나 설명을 검색하면 여러 스캔 프로그램에서 해당 디바이스를 읽거나 쓰는 위치를 따라갈 수 있습니다. XGB-XBCU와 XGB-XBMS 프로젝트를 지원합니다.

## 다운로드

[최신 버전 다운로드](https://github.com/minsoo0506/xg5000-device-map/releases/latest)에서 **Assets** 아래의 `-setup.exe` 파일을 내려받아 실행하세요. 설치 후 시작 메뉴에서 **XG5000 Device Map**을 열 수 있습니다.
