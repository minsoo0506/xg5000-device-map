# XG5000 Device Map

XG5000에서 사용하는 디바이스의 참조 관계를 살펴보는 Windows 프로그램입니다. 디바이스를 중심으로 관련 조건과 프로그램을 연결해 보여주므로 여러 스캔 프로그램에 걸친 관계를 탐색할 수 있습니다.

현재는 **예제 데이터와 이 프로그램에서 사용하는 JSON 파일**을 열 수 있습니다. XG5000 프로젝트 파일이나 변수 CSV를 직접 불러와 래더 관계를 자동으로 분석하는 기능은 아직 제공하지 않습니다.

## 설치하기

1. GitHub 저장소의 [Actions](../../actions/workflows/windows.yml)에서 **Windows installer**를 선택합니다.
2. 초록색 체크 표시가 있는 최신 실행을 선택합니다.
3. 실행 화면 아래의 **Artifacts**에서 `XG5000-Device-Map-Windows-Installer`를 내려받습니다. GitHub 로그인이 필요할 수 있습니다.
4. 내려받은 압축 파일을 풀고 `-setup.exe`로 끝나는 설치 파일을 실행합니다.
5. 설치가 끝나면 시작 메뉴에서 **XG5000 Device Map**을 실행합니다.

설치 파일에는 오프라인 환경을 위한 WebView2 설치 구성 요소가 포함되어 있습니다. 회사 PC에서는 보안 설정이나 설치 권한에 따라 설치가 제한될 수 있습니다.

## 예제 데이터 살펴보기

처음 실행하면 가상의 컨베이어 데이터가 표시됩니다. 다른 파일을 열었다가 다시 확인하려면 오른쪽 위의 **예제 열기**를 누르세요.

1. 왼쪽 목록에서 `M100`을 선택합니다. 위쪽 검색창에 주소나 주석을 입력해 찾을 수도 있습니다.
2. 가운데 관계도에서 `M100`을 읽는 조건과 `M100`을 변경하는 조건을 확인합니다.
3. 조건 묶음을 클릭하면 화면 아래에 프로그램명, 위치, 읽기 디바이스, 쓰기 명령과 메모가 표시됩니다.
4. 다른 디바이스를 클릭하면 해당 디바이스를 중심으로 관계도가 다시 표시됩니다.
5. 오른쪽 위의 **탐색 단계**에서 `+` 또는 `−`를 눌러 연결된 관계를 더 넓게 보거나 줄일 수 있습니다.

관계도는 마우스로 이동하고 확대·축소할 수 있습니다. 개별 항목을 드래그해 위치를 옮길 수도 있습니다.

## 직접 작성한 데이터 열기

오른쪽 위의 **관계 데이터 열기**에서 UTF-8로 저장한 `.json` 파일을 선택합니다. 데이터는 사용하는 PC에서 처리됩니다. 잘못된 파일을 선택하면 오류가 표시되며 기존에 열려 있던 데이터는 유지됩니다.

아래는 두 프로그램에 걸친 관계를 작성한 예입니다.

```json
{
  "name": "컨베이어 설비",
  "devices": [
    {"address": "P000", "comment": "기동 버튼"},
    {"address": "M100", "comment": "운전 허가"},
    {"address": "P020", "comment": "컨베이어 출력"}
  ],
  "rungs": [
    {
      "id": "main-10",
      "program": "MAIN",
      "location": "스텝 10",
      "reads": ["P000"],
      "writes": [{"address": "M100", "instruction": "OUT"}],
      "note": "기동 버튼을 사용한 운전 허가"
    },
    {
      "id": "conveyor-20",
      "program": "CONVEYOR",
      "location": "스텝 20",
      "reads": ["M100"],
      "writes": [{"address": "P020", "instruction": "OUT"}]
    }
  ]
}
```

파일을 열고 `M100`을 선택하면, 왼쪽에는 `P000`과 `MAIN`의 조건 묶음이, 오른쪽에는 `CONVEYOR`의 조건 묶음과 `P020`이 표시됩니다. 실제 배치는 연결 구조에 따라 달라질 수 있습니다.

### 항목 설명

| 항목 | 설명 |
| --- | --- |
| `name` | 화면에 표시할 프로젝트 이름. 생략할 수 있습니다. |
| `devices` | 관계도에 사용할 디바이스 목록 |
| `address` | 디바이스 주소. 빈 값이나 중복을 사용할 수 없습니다. |
| `comment` | 디바이스 주석. 생략할 수 있습니다. |
| `rungs` | 프로그램별 조건 묶음 목록 |
| `id` | 각 조건 묶음의 고유한 이름. 중복을 사용할 수 없습니다. |
| `program` | 조건 묶음이 속한 프로그램 이름 |
| `location` | 원본에서 확인할 수 있는 위치. 문자열로 입력합니다. |
| `reads` | 조건이나 명령의 입력으로 참조하는 디바이스 주소 목록 |
| `writes` | 변경되는 디바이스 주소와 명령 목록 |
| `instruction` | `OUT`, `SET`, `RST`처럼 표시할 쓰기 명령 |
| `note` | 조건 묶음에 대한 메모. 생략할 수 있습니다. |

`reads`와 `writes`에 넣는 주소는 모두 `devices`에 미리 등록해야 합니다. `reads`나 `writes`에 해당하는 항목이 없다면 빈 배열 `[]`을 사용하세요. 파일 형식이 맞지 않으면 화면에 표시되는 오류를 확인해 수정한 뒤 다시 열 수 있습니다.

## 관계도를 볼 때

연결선은 입력 데이터에 기록된 **참조 관계**를 보여줍니다. 접점의 반전, 병렬 조건, 실행 순서, 스캔 주기, SET·RST의 실제 동작까지 판별하지 않습니다. 관계도를 단서로 삼아 XG5000의 원본 래더와 해당 설비의 동작을 함께 확인하세요.

이 JSON은 XG5000에서 내보낸 파일 형식이 아닙니다. 직접 작성하거나 별도의 변환 과정을 거쳐야 합니다.
